# TU-403 지원금 구매 검증

지원금 신청 한 건에는 거래명세의 한 품목을 기재한다. 같은 물건을 같은 가격에 여러 개 산 경우 한 신청에 수량을 입력한다. 한 번에 다른 물건들을 결제한 경우 각각 신청하고, 기존 거래명세 첨부에서 해당 품목을 확인할 수 있게 한다. 신청·승인 단위는 기존 지원금 행이다.

## 신청·수정 API

대표자 신청 `apiFnd001`과 수정 `apiFnd003`의 요청·응답 형식과 DB 스키마는 그대로다. 새 검증은 아래 기존 값을 사용한다.

| 필드 | 역할 |
| --- | --- |
| `expenditureAmount` | 해당 품목의 지출 금액. 배송비를 포함할 수 있다. |
| `fixture.number` | 비품 수량 |
| `fixture.price` | 배송비를 제외한 비품 한 개의 실제 구매 금액 |
| `clubSupplies.number`, `clubSupplies.price` | 동아리용품 증빙에 입력한 수량과 개별 구매 금액 |

- 소프트웨어 이외의 비품 구매는 개별 단가 50,000원 이상이어야 한다. `개별 단가 × 수량 ≤ 지출 금액`이면 금액 검증을 통과한다. 개당 60,000원에 2개를 사고 배송비 5,000원을 냈다면 품목 소계는 120,000원이고, 지출 금액은 125,000원이다.
- 실물 동아리용품 구매에 입력한 수량과 단가도 같은 방식으로 소계를 대조한다. 개당 5만 원 기준은 비품 구매에 적용한다. 배송비 등 인정 비용은 품목 소계와 지출 금액의 차이로 기존 거래명세에서 확인한다.
- 과거 신청에서 구매 금액·개수·단가·분류를 유지한 채 설명이나 증빙을 수정하면 기존 금액으로 저장할 수 있다. 구매 정보가 바뀌면 같은 검증을 적용한다.
- 서로 다른 품목을 한 신청에 묶었는지는 집행부가 거래명세로 확인한다.
